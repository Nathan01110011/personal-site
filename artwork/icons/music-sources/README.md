# Music app icon sources

These are existing OS-era raster assets, rather than generated replacements.
The surrounding music player interfaces are built in local HTML/CSS.

- `windows-music.png`: original Winamp 2 32px icon from
  https://github.com/1j01/98/blob/master/images/icons/winamp2-32x32.png.
- `mac-music.png`: Classic Mac sound document icon, number 75, from
  https://github.com/bearz314/MacOS9-icons. Repository extraction/conversion
  copyright (c) 2020 Bearz314, MIT license in `MacOS9-MIT.txt`. Original Apple
  resource icons credited by that repository to NazoraioiSkadinaujo.
- `ubuntu-music.png`: Humanity `applications-multimedia` icon rendered to PNG
  from the unmodified `ubuntu-multimedia.svg` source included here. Humanity
  authors: Daniel Fore, Jonian Guveli and K. Vishnoo Charan Reddy.
  GPL version 2; see `Humanity-GPL-2.txt`.
- `android-music.png`: AOSP Gingerbread Music application icon, from
  https://github.com/aosp-mirror/platform_packages_apps_music/blob/gingerbread-release/res/drawable-hdpi/app_music.png.
- `ios-music.jpg`: original iOS 6 Music icon, from
  https://github.com/zagnut531/iOS-6-Icons/blob/main/iPad/Cropped%20icons/Music.jpg.

Imported 2026-10-06. Native alpha is preserved on the PNG assets. The iOS
square icon uses a CSS rounded mask, with no colour-key transparency removal.
