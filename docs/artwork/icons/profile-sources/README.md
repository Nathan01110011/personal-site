# Profile / Contacts icons

Original raster assets are used without colour-key transparency processing.

- Windows: Windows 98 Address Book, 32px, extracted icon catalog at
  https://github.com/ryokun6/ryos/blob/main/public/resources/windows-icon-catalogs/win98/applications/address-book.png
- Classic Mac: Mac OS 9 person/profile folder, resource 39, 64px, from
  https://github.com/bearz314/MacOS9-icons/blob/master/png%2064px/39.png
  Extraction/conversion license: ../music-sources/MacOS9-MIT.txt.
- Ubuntu: original Humanity addressbook.svg, rendered as a 128px PNG. The
  unmodified SVG is included as ubuntu-address-book.svg. From
  https://github.com/mk-pmb/ubuntu-icon-theme-humanity/blob/master/Humanity/apps/128/addressbook.svg
  License: ../music-sources/Humanity-GPL-2.txt.
- Android: AOSP Gingerbread Contacts launcher, from
  https://github.com/aosp-mirror/platform_packages_apps_contacts/blob/gingerbread-release/res/drawable-hdpi/ic_launcher_contacts.png
  License: ../music-sources/AOSP-Apache-2.0.txt.
- iOS: original iOS 6 Contacts icon, exported from iPad by zagnut531:
  https://github.com/zagnut531/iOS-6-Icons/blob/main/iPad/Cropped%20icons/Contacts.jpg
  Rounded shape is applied in CSS to the square image.

These are local, uncommitted draft assets; imported 6 October 2026.
