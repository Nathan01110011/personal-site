# Wallpaper sources

`ios-water-drops.jpg` is the existing iOS 5 water-drop wallpaper previously
loaded remotely from:
https://wallpaperswide.com/download/ios_5_wallpaper___water_drops-wallpaper-1440x900.jpg

Bundled unchanged so the iOS homescreen does not depend on a third-party
image request. The build copies this folder into `docs/artwork/` as well.
